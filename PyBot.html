AI Discord Bot | The XIV Project

I have created a Discord bot that uses an AI model to generate
responses to questions related to technology, coding, or cybersecurity.

You can invite the bot to your own server using this link: XIV

I made it using Python and the discord.py library.
It’s currently running only on my own server,
but I plan to host it on a cloud platform soon.

The bot is still in development,
so if you have any suggestions or feedback,
please let me know!
It might be offline sometimes due to hosting limitations,
but you can still add it to your server and it will work when online.
